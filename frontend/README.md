# Frontend for a DevOps Portfolio Project

This frontend is the user-facing layer of a larger DevOps practice project. The application itself is a simple blog interface, while the real learning value comes from how it is packaged, connected to services, and deployed in a repeatable way.

## DevOps relevance

This part of the project helps demonstrate:

- frontend containerization
- environment-based configuration
- communication with a backend API
- deployment readiness for cloud environments
- separation between application code and platform concerns

## Local development

```bash
cd frontend
npm install
npm run dev
```

## Deployment note

The frontend is expected to work with the backend and infrastructure configuration defined in the project root and the Docker/Terraform folders.
